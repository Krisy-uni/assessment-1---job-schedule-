# Calendar-based Work Scheduling Web Application

A mobile-first web application designed to support job scheduling, allocation and worker management for small trade businesses.

## Setup

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a web browser or local preview.

## Architecture Summary

The application uses a simple web-based architecture. The user interface is implemented using HTML and CSS. The current prototype focuses on role-based job scheduling and allocation workflows for Owner and Worker users.

## Known Limitations

The current implementation is a sample application and does not yet implement all functions shown in the Figma prototype. Some backend functionality and persistent data storage are not yet available.
